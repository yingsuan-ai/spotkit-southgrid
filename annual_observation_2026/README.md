# 《2026 南网五省电力现货年度观察》

本目录是 SpotKit-SouthGrid 综合包的一部分：一份**开源**的年度观察报告 + 数据集。

- `observation_2026.md` — 年度观察正文（市场拐点 / 售电盈利塌方 / 价格信号 / VPP 价值重估 / 大工业用能管理 / 启示）。
- `data/metrics_2026.csv` — 支撑指标数据集（含 scope / source_note / as_of 字段，便于引用与溯源）。

## 数据口径与免责

- 数据来自南方能源监管局、各省电力交易中心及行业媒体的**公开报道梳理**，截至 **2026-11-12**。
- 所有数字以官方发布为准；本目录不构成投资建议。
- 本仓库 `../sample_data/` 内电价为**脱敏教学样本**，不可用于真实结算。
- 如需对**自有数据**做完整诊断与优化，请使用算电宝™（见仓库根 README）。
