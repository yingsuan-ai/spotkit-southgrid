# PlantAudit · 虚拟工厂用电体检（开源外壳）

输入负荷曲线 + 基础档案（变压器容量 / 行业 / 省份），对「负荷率 / 需量压力 / 峰段占比 / 负荷波动」四个维度做透明评分，生成一份自包含的 HTML「工厂用电健康度」报告。

## 用法

```bash
# 演示：自带样例虚拟工厂
python plantaudit.py --demo --out plant_audit_report.html

# 自定义：自有负荷曲线
python plantaudit.py --load load.csv --capacity 1000 --name "我的工厂" --province 云南
```

输入 CSV 字段：`hour,load_kw`

## 评分维度（透明可复现）

| 维度 | 含义 | 越好方向 |
|------|------|----------|
| 负荷率 | 日电量 /（峰值×24h） | 越高越省（目标≥60%） |
| 需量压力 | 峰值 / 变压器容量 | 越低越安全 |
| 峰段占比 | 峰段电量 / 总电量 | 越低越省 |
| 负荷波动 | 负荷变异系数 | 越平稳偏差风险越低 |

## ⚠️ 边界说明

评分公式完全透明、可复现，用于建立直觉；它与算电宝™闭源内核（L2 约束优化、核销引擎、分润结算）无关，也**不构成任何降本承诺**。真实诊断请以算电宝专业版为准。本工具是算电宝免费基础版「全年免费体检、数据不出本机」体验的开源镜像。
